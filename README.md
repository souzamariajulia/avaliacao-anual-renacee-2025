RENACEE-MD 2025 — Análise de Dados

Projeto de Engenharia de Dados voltado à organização, auditoria, padronização e análise dos dados do RENACEE-MD 2025.

Objetivo

Construir um fluxo de tratamento e análise de dados que permita compreender o perfil dos participantes e, posteriormente, avaliar os resultados do projeto.

Tecnologias

Python

Pandas

Jupyter Notebook

VS Code

Git e GitHub

Excel

Estrutura do projeto

data/: bases originais, intermediárias e processadas (não publicadas).

notebooks/: exploração, auditoria e análise dos dados.

src/: scripts Python.

docs/: documentação.

reports/: relatórios e resultados.

Etapas

Exploração inicial dos dados.

Auditoria e padronização das variáveis de perfil.

Construção de indicadores e KPIs de perfil.

Visualização das características dos participantes.

Análise dos dados de avaliação.
